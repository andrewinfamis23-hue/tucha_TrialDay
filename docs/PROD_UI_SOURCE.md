# Откуда взят интерфейс

Интерфейс песочницы основан на UI рабочего модуля TuchaCRM из Git-коммита
`12df4b9` (`fix(crm): keep generated asset text out of database`). Это
зафиксированная версия, которая была подтверждена как PROD на дату подготовки
песочницы.

Из PROD без изменений перенесены:

- `static/src/css/tucha_theme.css`;
- `static/src/css/fix_layout.css`;
- `static/src/fonts/Inter-Variable.ttf`;
- `static/src/img/brand.svg`.

Навигация и шаблоны входа адаптированы к учебному модулю. В песочнице ровно
шесть тех же верхних разделов, но действия работают только с локальными
моделями и фейковыми данными.

Не переносились рабочие модели, адреса, пароли, токены, уведомления,
интеграционные клиенты и подключения к WMS. Nginx публикует локальную CRM по
адресу `http://localhost`, а Odoo доступен ему только внутри Docker-сети.
